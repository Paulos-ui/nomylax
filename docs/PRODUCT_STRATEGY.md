# Product Strategy

Nomylax starts with one narrow problem: an autonomous agent needs enough authority to do useful financial work without inheriting unrestricted treasury authority.

## Wedge
1. Developers register an agent and define a Financial Constitution.
2. The agent submits economic intent rather than receiving unrestricted wallet authority.
3. Nomylax authenticates, evaluates deterministic policy and risk, simulates where applicable, and either blocks, holds for review or allows the execution path.
4. Every decision produces evidence an operator can inspect.

## Expansion path
**Agent integrations → protocol adapters → policy automation → team controls → infrastructure layer.**

Agent frameworks can integrate at the intent boundary. Protocol adapters can constrain supported DeFi actions instead of accepting arbitrary calls. Teams can add shared policy management, monitoring, approval workflows and audit exports. The long-term opportunity is a reusable control layer that complements wallets, agent frameworks and protocols rather than replacing them.

## Current / prototype / planned
**Current:** deterministic policy/risk logic, agent controls, Shadow Mode, Safe Mode, audit surfaces, Base-oriented execution architecture, wallet authentication and Control Copilot explanation.

**Prototype / environment dependent:** live settlement and external agent connectivity require correct server configuration and should be demonstrated only when verified.

**Planned:** richer protocol adapters, persistent production repository, multi-user/team policy administration, stronger observability and additional approval workflows.
